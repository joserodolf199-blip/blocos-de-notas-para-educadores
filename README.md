# 🎓 Atlas Digital

O **Atlas Digital** é uma plataforma desenvolvida para auxiliar professores e contribuir com a organização e o controle de qualidade no ambiente educacional.

O projeto busca oferecer uma experiência moderna, organizada e intuitiva, reunindo funcionalidades e recursos voltados ao ambiente escolar.

## 🔐 Página de Login

A plataforma possui uma interface de autenticação onde os usuários podem acessar o sistema utilizando suas credenciais.

Entre os recursos disponíveis estão:

* 📧 Campo para inserção de e-mail;
* 🔒 Campo para inserção de senha;
* ⚠️ Área para exibição de mensagens de erro;
* 🔑 Recuperação de senha;
* 👤 Opção para cadastro de novos usuários;
* 📱 Interface desenvolvida pensando em diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura das páginas;
* **CSS3** — Estilização e responsividade;
* **JavaScript** — Interatividade e funcionalidades da aplicação;
* **Google Fonts** — Tipografia utilizada na interface.

## 📚 Funcionalidades

O **Atlas Digital** é composto por diferentes módulos voltados à organização e gestão do ambiente educacional. Atualmente, o projeto conta com as seguintes páginas e funcionalidades:

| Página                        | Descrição                                                           |
| ----------------------------- | ------------------------------------------------------------------- |
| 🏠 **Home**                   | Página principal de acesso ao sistema e navegação entre os módulos. |
| 📊 **Painel**                 | Área central para acompanhamento das informações do sistema.        |
| 📝 **Avaliação**              | Módulo destinado ao gerenciamento de avaliações dos alunos.         |
| 📑 **Boletim**                | Consulta e organização das notas e resultados acadêmicos.           |
| 📅 **Frequência**             | Controle e acompanhamento da frequência dos alunos.                 |
| 👨‍🎓 **Perfil do Aluno**     | Área destinada às informações e dados do aluno.                     |
| 👨‍🏫 **Perfil do Professor** | Área destinada às informações e dados do professor.                 |
| ⚙️ **Configurações**          | Gerenciamento e personalização das configurações do sistema.        |
| 📋 **Cadastro**               | Página destinada ao cadastro de usuários.                           |
| 🔐 **Recuperação de Senha**   | Sistema para recuperação de acesso à conta.                         |
| 📈 **Relatório**              | Área destinada à geração e visualização de relatórios.              |
| 📂 **Controle de Dados**      | Módulo relacionado ao gerenciamento e organização de informações.   |

### 🔄 Navegação

As páginas possuem um sistema de navegação lateral que permite ao usuário acessar diferentes módulos da plataforma. Durante o desenvolvimento, os links da barra lateral foram reorganizados e atualizados para manter a navegação consistente entre as páginas.
