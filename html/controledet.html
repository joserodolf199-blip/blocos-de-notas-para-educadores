SOBRE O CONTROLE DE TURMA:

ORGANIZAÇÃO EM CARDS (TURMAS):

  • As turmas são dispostas de forma modular em cartões individuais.
  • Cada card possui um ícone de identificação e exibe a lista simplificada dos alunos pertencentes a cada turma.

PAINEL E LAYOUT:

  • Apresenta um visual limpo e estruturado com contraste de cores.
  • A interface é organizada para facilitar a navegação e o gerenciamento das turmas em um só lugar.

CONEXÃO COM OS MÓDULOS DO SISTEMA:

  • Essa área serve como ponto de partida para navegar diretamente para outras telas do sistema.
  • Boletim: para inserção e visualização das notas.
  • Frequência: para registro diário de chamadas.
  • Avaliações e relatórios: para análise individual ou coletiva do desempenho escolar.

PERGUNTAS FREQUENTES

Como criar uma nova turma?

Clique em "Adicionar turma" e preencha as informações solicitadas para criar uma nova turma.

Como acessar uma turma?

Clique no botão "Acessar turma" correspondente à turma que deseja visualizar.

Posso adicionar mais de uma turma?

Sim. É possível adicionar novas turmas conforme a necessidade da instituição.
